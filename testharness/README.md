# Test Harness

This folder contains the reusable Python launcher for Factorio mod integration tests. It expects the target mod to provide its own Lua assertions, report writer, and `tools/test/harness.json`.

Start here:

- `docs/INTEGRATION.md`: generic Lua/Python contract.
- `docs/MOD_CONFIG.md`: `tools/test/harness.json` reference.
- `docs/EXAMPLE_INGREDIENT_SCRAP.md`: large reference integration.
- `docs/EXAMPLE_PURE_IT.md`: small report-only example.
